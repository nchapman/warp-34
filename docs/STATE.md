### Phase 5 Deliverables

8. **Phase 5.1 — Paged `TQ4` (`132 B`/row) & `K8V4` (`272 B` K + `132 B` V) KV Cache (`crates/w34-kernels/csrc/ops/op_paged_attn.cu`, `crates/w34-host/src/cache.rs`):**
   - **Single-Warp Register `wht256_warp`:** Stages `h = 1..16` use intra-warp `__shfl_xor_sync` butterfly shuffles and stages `h = 32, 64, 128` operate in-register across each lane's `v[0..7]` with zero shared memory or block barriers, matching `warp3090`'s Seed-42 Rademacher + WHT-256 transform to 0 ULP.
   - **Concurrent 2-Warp `kv_cache_write_kernel` & Fused `paged_attention_f16`:** Warp 0 encodes `K` (`FP16`, `BF16`, `Q8_0`, or `TQ4`) while Warp 1 encodes `V` concurrently; `paged_attention_f16_kernel` fuses `Q' = WHT256 · diag(s) · Q` pre-rotation before the KV loop, sub-block-grouped `TQ4`/`Q8_0`/`FP16` dot/axpy inside the 4-warp online-softmax loop, and `O = diag(s) · WHT256 · O'` inverse rotation before writing output.
   - **`FirstLast2` (`2.52×`) & `K8V4FirstLast2` (`1.97×`) Policies:** Keeps boundary full-attention ordinals `{0, 1, N-2, N-1}` in `FP16` and compresses interior layers with rotated `TQ4` or `K8V4`, exposed via `--kv-format fp16|tq4|k8v4|firstlast2|k8v4-firstlast2`.
9. **Phase 5.2 — Multimodal Vision (`Qwen3_VisionTransformer`: `crates/w34-kernels/csrc/ops/op_vision.cu`, `crates/w34-host/src/vision.rs`, `crates/w34-host/src/{model,server}.rs`):**
   - **Image Preprocessing & `smart_resize`:** Banker's-rounded (`round_ties_even`) `factor = 32` aspect-preserving resize within `[min_pixels, max_pixels]`, PyTorch-aligned (`a = -0.75`) bicubic interpolation, `mean = 0.5 / std = 0.5` normalization, `temporal_patch_size = 2` duplication, and `2×2` spatial-merge patch ordering (`[N_patches, 1536]`).
   - **GPU `Qwen3VisionEncoder` (`op_vision.cu` + `vision.rs`):** 2D bilinear `pos_embed` interpolation, 24/27-layer ViT with `LayerNorm`, 2D axial `RoPE` full attention (`cu_seqlens` per image), `GELU` MLP, `PatchMerger` (`2×2` -> `4 * hidden_size` -> `out_hidden_size`), and `w34_embedding_splice_f16` into `<|image_pad|>` token positions.
   - **3D `mRoPE` & Content-Hashed `MambaRadixCache`:** `compute_mrope_positions` (`[3, seq_len]` `(T, H, W)` planes + `mrope_delta` consumed by `w34_fused_qk_rmsnorm_rope_gate_strided_f16`), `compute_multimodal_radix_key` (mixing 64-bit FNV-1a image content hash into `<|image_pad|>` radix keys so identical images hit warm `MambaRadixCache` checkpoints while distinct images never alias), and OpenAI `/v1/chat/completions` `image_url` support.
10. **Phase 5.3 — `Qwen3.5` / `3.6` Hybrid MoE (`Qwen3_5MoeForConditionalGeneration`: `crates/w34-kernels/csrc/ops/op_moe.cu`, `crates/w34-host/src/{loader,model}.rs`):**
    - **Top-K Softmax/Sigmoid Router (`w34_moe_topk_router_f16`):** Supports up to `1024` experts and `top_k <= 32` with optional `norm_topk_prob` renormalization and deterministic tie-breaking.
    - **Two-Stage Fused `W4A16` (`U4B8NMajor`) & `FP16` MoE Kernels (`w34_moe_w4a16_gate_up_silu_f16`, `w34_moe_w4a16_down_accum_f16`, `w34_moe_f16_gate_up_silu`, `w34_moe_f16_down_accum`):** Stage 1 fuses routed `gate_proj + up_proj + SiLU(gate) * up` per `(token, slot)` pair; Stage 2 fuses routed `down_proj` weighted accumulation across `0..top_k` with `shared_expert * sigmoid(shared_expert_gate)` in a single deterministic write without `atomicAdd`.
    - **End-to-End `TP=1` & `TP=2` Engine Support:** Shards both routed experts (`moe_intermediate_size / tp_size`) and `shared_expert` (`shared_expert_intermediate_size / tp_size`) across TP ranks while keeping `router_gate` and `shared_expert_gate` replicated for identical routing decisions across ranks without extra collectives.
